# Mr. Chopsticks website

Static website for Mr. Chopsticks in Denton, Texas.

## Project structure

- `index.html` — page markup, styles, and behavior
- `assets/` — images, videos, icons, and social-preview media
- `netlify.toml` — Netlify publishing and cache configuration
- `robots.txt` and `sitemap.xml` — search-engine discovery files
